# Gemini 주민 대화 실행하기 (Windows PowerShell)

최신 Windows 단계별 안내는 프로젝트 루트 `실행순서.md`를 확인하세요.

주민 앞에서 E키를 누르면 질문창이 열립니다. 루미(레이다·위성), 모아(에어로스페이스: 우주·항공·지상·해양), 토비(엔진·지상방산), 별이(발사체), 파도(선박·해양설비)는 자기 집 자료를 근거로 답합니다. 최근 5회 질문/답변을 후속 질문의 문맥으로 전달하며, 창을 닫으면 대화는 지워집니다. 질문과 최근 대화, 관련 자료는 Gemini로 전송됩니다.

## 1. 준비
Node.js와 Python 3.10 이상이 필요합니다. 이 변경이 들어 있는 프로젝트 폴더에서 터미널을 엽니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
```

## 2. 프로젝트 루트 .env 설정

최상위 `.env` 파일에 다음을 저장하세요. 기존 설정은 보존하고 키는 본인이 발급받은 값으로 입력합니다.

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
GEMINI_API_KEY=본인이_발급받은_키
GEMINI_MODEL=gemini-3.1-flash-lite
```

키에 `VITE_` 접두사를 붙이지 마세요. `.env`는 Git에서 제외되며 실제 키를 소스나 설정 예시에 넣으면 안 됩니다.

## 3. 서버와 게임 실행

프로젝트 루트에서 API 서버를 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --env-file .env
```

`--env-file .env`가 Python 서버에 설정을 전달합니다. 셸에 이미 같은 환경변수가 설정되어 있다면 셸 값이 우선합니다. 키나 모델을 바꾸면 API 서버를 재시작하세요. Gemini 키가 있으면 OpenAI보다 우선하며 OpenAI 임베딩을 호출하지 않습니다. 모델은 계정에서 generateContent와 구조화 JSON 출력을 지원하는 ID로 변경할 수 있습니다.

새 터미널에서 실행합니다.

```powershell
npm install
npm run dev
```

http://127.0.0.1:5173 에 접속합니다. 서버 두 개를 모두 켜두세요. `.env`를 바꾸면 게임 서버를 재시작하세요.

## 4. 확인
탐지의 집에서 루미 앞에 서서 E키 → 위성 주제 선택 → 질문 보내기 → “더 쉽게 설명해줘”를 보냅니다. 답변의 ‘AI 답변’과 출처를 확인하세요. 다른 주민에게도 담당 주제를 질문하세요. 키가 없으면 ‘도감 모드’로 동작합니다. /api/health의 llm 표시는 키 설정 여부일 뿐, 실제 연결 성공은 질문 응답으로 확인해야 합니다.

연결 오류 시 키, 모델 접근 권한, Google AI Studio의 사용 한도 및 서버 터미널을 확인하세요. 실패 시 입력을 유지하며 질문을 다시 보낼 수 있습니다. 서버의 하루 호출 한도 기본값은 100회이며 프로세스 재시작 시 초기화됩니다. 공개 배포에는 별도 Python 서버 호스팅과 인증/사용량 관리가 필요합니다.

## 검증 범위
키 없이 자동 테스트와 빌드를 실행할 수 있습니다. 로컬에서 gemini-3.1-flash-lite로 별이의 실제 질문과 AI 답변 수신을 확인했습니다. 모델 접근 권한·한도·응답 시간은 계정과 Google 서비스 상태에 따라 달라집니다.
