# HANWHA OCEAN — OCEAN EXPERIENCE

한화오션의 상선, 특수선, EPU 사업을 공개 자료에 기반해 소개하는 **비공식 교육용** 정적 전시관입니다. 회사가 발급하는 인증 서비스가 아닙니다.

## 실행

`index.html`을 브라우저에서 직접 열면 됩니다. 별도 서버와 외부 JavaScript 라이브러리가 필요하지 않습니다. 마을 프로젝트에서는 오션의 집 오른쪽 `사업부 둘러보기`에서 E를 누르면 열립니다.

## 조작

- **상선 게임:** 시작 후 방향키 또는 WASD, 모바일에서는 화면의 방향 버튼으로 이동합니다. 60초 안에 암초를 피해 오른쪽 아래 항구에 도착하면 완료됩니다. 암초·경계와 충돌하면 게임 점수만 감점됩니다.
- **특수선 게임:** 시작 후 소나 스캔 버튼을 누릅니다. 잠시 보이는 목표 3개를 45초 안에 모두 선택하면 완료됩니다. 실제 군사 탐지 절차를 재현하지 않습니다.
- **EPU 게임:** 시작 후 설비 블록을 해당 자리에 끌어 놓습니다. 모바일에서는 블록을 누른 뒤 자리를 누를 수 있습니다.
- **퀴즈:** 상선·특수선·EPU에서 각 3문항을 풉니다. 종료하면 총점과 분야별 결과가 표시됩니다.
- **일시정지:** 시간제 게임에서 사용 가능합니다. 다른 게임 탭으로 이동하면 진행 중인 게임은 일시정지됩니다.
- **진행 상황:** 세 게임과 퀴즈를 완료하면 비공식 OCEAN EXPLORER 배지가 표시됩니다. 기록은 이 브라우저에만 저장됩니다.
- **사운드:** 상단 버튼을 누르면 이 페이지에서 합성한 파도 소리가 켜집니다. 마을의 배경 음악과는 별개입니다.

`index.html`, `style.css`, `script.js`만으로 동작합니다. 화면의 공식 자료 링크는 내용을 확인하기 위한 외부 링크이므로 인터넷 연결이 있어야 열립니다. 게임 제한 시간·점수·설비 배치는 학습용 가상 설정입니다.
